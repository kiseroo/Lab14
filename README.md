# Lab 14: Maven-Based Java Project with Git Workflow and GitHub Actions

This repository demonstrates a Git workflow for a Maven-based Java project, including:
- Feature branching
- Release management
- Hotfixes
- CI/CD with GitHub Actions (JUnit, Checkstyle, JaCoCo)

## Commands

- Run tests: `mvn test`
- Check code style: `mvn checkstyle:check`
- Generate coverage report: `mvn jacoco:report`
- Verify coverage: `mvn jacoco:check`
